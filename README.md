# IDE (working name)

A native, GPU-rendered AI-agent IDE in Rust: isolated git worktrees per task, first-class coding-agent sessions (Claude Code, Codex, Gemini CLI, OpenCode, and any ACP agent), an embedded GPU terminal, review with line-anchored comments dispatched to agents, and a CLI for orchestration.

Start here: `AGENTS.md`, then `docs/02-STACK.md`, `docs/03-ARCHITECTURE.md`, `docs/04-IMPLEMENTATION-PLAN.md`. Put the design in `design/`.
